# GCL Documentation

A complete, beginner-friendly guide to GCL — the Gnuchan C-Like Language.
It covers the CLI, types, memory, structs, classes and every Part of the
GCL language as bundled with GnuChanIDE.

---

## 1. GCL is HUB LANGUAGE

GCL is the hub language of GnuchanOS: every module (`.gcsf`, `.gclib`,
`.so`, `.dll`, `.a`) comes together here. It is linux/focus by design but
it can support Windows too (no macOS, no Android).

### Running a script

```text
gcl -flags main.gcsf -o path/output        # or just: -o output
gcl -flags -run path/main.gcsf             # or just: -run main.gcsf
```

### CLI flags

```text
gcl -lexer  file.gcsf | file.gclib
gcl -parser file.gcsf | file.gclib
gcl -ast    file.gcsf | file.gclib
gcl -ir     file.gcsf | file.gclib
gcl -debug -run file.gcsf

gcl -linclude path -llib path -lextern path -run main.gcsf
```

### File types

```text
.gcsf    # script file
.gclib   # library/module
.gctf    # text file
.gcdata  # json with file + "#//" comment line support
```

> `D:\GnuchanOS\language\BUILD` is where the output `gcl`, `.gcsf`,
> `.gclib`, `.so`, `.dll`, `.a` files live. Keep compiler trash out of it.

## 2. Language Algorithm (pipeline)

```
GCL Source #// .gclib/extern -> .gcsf/extern -> main.gcsf
     │
     ▼
src/
├── FastIR/                      # interpreter
│
├── SharedPipeline/
│   ├── Linker/
│   ├── Lexer/
│   ├── Parser/
│   ├── Semantic/
│   ├── TypeChecker/
│   ├── Memory/
│   ├── GarbageCollector/
│   ├── AST/
│   ├── Diagnostics/
│   ├── Ir/
│   └── Common/

# .gclib/extern -> include .gcsf/extern -> main.gcsf
# SharedPipeline -> FastIR
```

The source is merged (`#lib` / `#include` / `#extern`) first, then pushed
through the SharedPipeline (lexer -> parser -> semantic -> typecheck ->
IR) and finally executed by FastIR.

## 3. Memory management

```text
            Program
                │
    ┌───────────┼───────────┐
    │           │           │
    Stack       Heap      Static Data
    │           │
```

## 6. Module system

### Including a script (classic C-like)

```gcsf
#include "script.gcsf"      // or <script.gcsf>
// how to call: member
```

### Module / library system

```gcsf
#lib "library.gclib"        // or <library.gclib>
// how to call: library.member
```

### Native libraries (.so, .dll, .a)

```gcsf
#extern "raylib.dll"        // or <raylib.so>
    #register void InitWindow(int width, int height, const char *title);
    #register void CloseWindow(void);

// how to call: InitWindow(300, 300, "uwu");
```

## 7. Preprocessor / macros

These macros are for `.gclib` and included `.gcsf` files — not for
`main.gcsf`:

```gcsf
#register    // from #extern <raylib.dll> -> .so, .dll -> #register type function()
#ifdef
#ifndef
#if
#elif
#else
#endif
```

`#if` supports: `gnuLinux`, `gnu_linux`, `gnu`, `linux`, `windows`.
You can use it in `main.gcsf`, included `.gcsf` and `.gclib`.

```gcsf
#define           // normal macro
#undef
#warning "text", "text", variable, variable   // yellow text
#error   "ERROR!!"                            // red text, stops build
#debug   "error message"                      // blue text after error
```

Output colors:

```text
#debug ..., ...   // blue
#warning ..., ... // yellow
#error ..., ...   // red
```

## 8. main() entry

`main()` is only required for `main.gcsf` — an included `.gcsf` does not
need one. All of these forms are accepted:

```gcsf
int main(void) { return 0; }
int main() { return 0; }
int main(int argc, char *argv[]) { return 0; }
int main(int argc, char **argv) { return 0; }
int main(int argc, char *argv[argc]) { return 0; }
```

## 12. scanf — safer than vanilla C

```gcsf
scanf("%type", text);
```

Runtime checks:

- Detect buffer overflow.
- Prevent writing past the buffer.
- Emit a `#warning` if the input exceeds the buffer size.
- Truncate the input safely.
- Always null-terminate the string.

## 13. char and gcChar (strings)

`char` is not vanilla char in GCL:

```gcsf
char TEXT = 'a';   // 1 utf-8 char
```

### Stack UTF-8 string (immutable)

```gcsf
gcChar TEXT[] = "this is lenght + UTF-8 based char system focus more safe stack use with const";
```

- UTF-8 encoded
- Length-aware
- Stack allocated
- Immutable
- Fixed size

### Heap UTF-8 string (mutable)

```gcsf
gcChar *TEXT = "this in heap UTF-8 string real strings";
```

- UTF-8 encoded
- Length-aware
- Heap allocated
- Mutable
- Dynamic size

The heap string is freed automatically at program exit, or you can call
`TEXT.free()` manually — after that `TEXT` becomes null and cannot be used
until it gets a new value:

```gcsf
if (TEXT != null) {
    // safe to use
}
```

## 14. Arrays

### Vanilla C arrays

```gcsf
char alphabet[] = {'a', 'b', 'c'};
char game[]     = "Half Life 3";
char games[][32]  = {
    "half life 3",
    "left 4 dead 3",
    "team fortress 3"
};

char ***games = malloc(sizeof(char ***) * 4);   // 3D malloc
```

Runtime checks:

- Check allocation size.
- If the requested size exceeds the maximum limit, automatically allocate
  a larger block and emit a `#warning`.
- Detect allocation failure.

Memory management:

- Call `free(games);` before program exit.
- If `free()` is called twice, emit a `#warning`.
- After `free()`, automatically set `games -> null`.

### Vanilla GCL arrays

```gcsf
gcChar a = 'a';                      // utf-8 char
gcChar game[] = "Half Life 3";
gcChar *game = "Half Life 3";

// type identifier[] @dimension_size = {}

gcChar alphabet[] @1 = {'a', 'b', 'c'};   // utf-8 char array/list
```

The `@N` syntax sets the maximum dimension level (`@1` = 1D, `@2` = 2D,
...). There is no `[][][][]` — you write `@4` instead.

```gcsf
type identifier[] @2 = {
    {           // 0D dimension
        {       // 1D dimension
            {   // 2D dimension
            }
        }
    },
}

gcChar gamesgames[container size][inside container char size] @3 = {
    { "game 0", { "info", { "Half-Life",      1998, 10 } } },
    { "game 1", { "info", { "Portal",         2007, 10 } } },
    { "game 2", { "info", { "Counter-Strike", 2000,  9 } } },
    { "game 3", { "info", { "Left 4 Dead 2",  2009, 10 } } }
};
    // : number means dimension size

gcChar *gamesgames[] @3 = {   // : number means dimension size
    { "game 0", { "info", { "Half-Life",      1998, 10 } } },
    { "game 1", { "info", { "Portal",         2007, 10 } } },
    { "game 2", { "info", { "Counter-Strike", 2000,  9 } } },
    { "game 3", { "info", { "Left 4 Dead 2",  2009, 10 } } }
};
    // no need to malloc
```

### Number arrays

```gcsf

```

## 15. Memory: malloc / gcMalloc / free

```gcsf
#define MAX_PLAYER 10
typedef struct Players {
    gcChar *name;   // regular string size, more runtime safe
    int8    age;
} Player;
```

There are 2 ways to build the array.

### First way: regular malloc

```gcsf
Players *Player_List = malloc(reserve=sizeof(Player*) * MAX_PLAYER);

Player[index].Name
Player[index].age

free(Player_List);   // frees and sets it to null
```

### Second way: easy and safe (gcMalloc)

```gcsf
Player *Player_List = gcMalloc(reserve=MAX_PLAYER, extra=10);
```

- Creates an array with `MAX_PLAYER` capacity.
- If the array becomes full, automatically expands by `+10` elements.
- Example growth: `10 -> 20 -> 30 -> 40 -> ...`

Memory management:

- You may call `free(Player_List)` manually.
- If you don't, GCL automatically frees the memory before program exit.

## 24. Classes

### 101

```gcsf
class no_head() {
    void call() {}
}   //# no_head.call()

class with_head() {
    void head() {
        int age = 30;

        return 0;
    }

    void call() { }
}   //# with_head().call(), .age
```

### Real example with inheritance

```gcsf
class FATHER() {
    @return
    gcChar Call() {
        return "where are you";
    }
}

class CHILD(FATHER) {
    void head(gcChar name, int8 age) {
        gcChar name = name;
        int8   age  = age;

        return 0;
    }

    void talk() {
        // # @return -> no need () only return
        gcChar what = FATHER.Call;

        if (what == "where are you") {
            printf("i'm coming father!! \n");
        }

    }

    int age() {
        return age;
    }
}

FATHER ThisFather = FATHER();   // no head means ()
CHILD  ThisChild  = CHILD(ThisFather);

printf("FATHER CALL: %s", ThisFather.Call());

printf("Child Name: %s \n", ThisChild.name);
printf("Child Age: %d \n", ThisChild.age());
printf("FATHER CALL From Child No Header: %s \n", ThisChild.Call());
printf("FATHER CALL From Child With Header: %s \n", ThisChild.talk());
```

## 25. Tips

- Files use `.gcsf` (script) and `.gclib` (library) extensions.
- GCL keywords autocomplete in the editor: `#include`, `#lib`, `#extern`,
  `#register`, `struct`, `class`, `tuple`, `dict`, `enum`, `printf`,
  `scanf`, `gcMalloc`, ...
- Pipeline: lexer -> parser -> semantic -> typecheck -> IR -> interpreter.
  Run `gcl -lexer / -parser / -ast / -ir <file>` to inspect each stage.
- This doc is bundled with GCL. More: `gcl_doc.md` in the repo root.
